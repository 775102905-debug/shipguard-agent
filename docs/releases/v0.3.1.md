# ShipGuard v0.3.1 Release Notes

## 概述

v0.3.1 是 MCP 稳定性与一致性安全补丁，增强 MCP Server 的异常处理、安全性测试验证、Web vs MCP 一致性验证，以及全路径脱敏覆盖。

## 变更内容

### 安全修复

- **服务端路径泄露修复**：`_validate_zip_path` 错误信息中的白名单目录路径改为相对路径显示，不再暴露服务端绝对路径。
- **增强脱敏覆盖验证**：新增脚本验证 MCP 输出、API 响应、Markdown 报告三路径脱敏一致性。

### 新增测试

| 测试脚本 | 覆盖内容 |
|----------|----------|
| `compare_web_mcp_reports.py` | Web API vs MCP 一致性（good/bad），脱敏一致性，MCP 工具集成测试 |
| `smoke_mcp_concurrency.py` | 并发 10 次审查、交替 8 次重复调用、并发路径泄露检查 |

### 增强测试

`smoke_mcp.py` 从 14 个检查增至 30+ 检查，新增：
- 空 ZIP 友好失败
- 损坏 ZIP 友好失败
- 超大 ZIP 拒绝
- 路径泄露检测
- 不执行代码验证
- bad_project 审查验证

### 文档更新

- `docs/mcp_usage.md`：新增已知限制章节，补充安全边界说明
- `docs/releases/v0.3.1.md`：本文件

## 安全验证

- MCP 输出无服务端绝对路径泄露
- Web 报告、MCP 摘要、错误信息三路均经过 `redaction_service.redact()`
- FAKE_* 测试值保留，真实形态假样例（sk-*, ghp_*, PRIVATE KEY 等）脱敏
- 所有错误信息可读，不包含 Python 异常堆栈中的敏感路径
